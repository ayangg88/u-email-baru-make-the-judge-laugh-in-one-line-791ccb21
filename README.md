One funny line, 200 characters or fewer, written to make the AI judge laugh.

## The line

> I've been funny exactly once, and I spent it on this sentence.

62 characters. A self-consuming joke: the setup promises one moment of
funniness, and the punchline spends it on the sentence itself — the laugh
lands at the end, with nothing left to explain.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
